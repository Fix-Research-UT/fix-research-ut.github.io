# Fix Research Group website

Static site (HTML + CSS, no build step).

## Publish with GitHub Pages
1. Create a new GitHub repo and push the contents of this folder to the `main` branch.
2. In the repo: **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`**.
3. The site goes live at `https://<username>.github.io/<repo>/` after a minute or two.

## Edit
- Content: `index.html`
- Styling and colors: `style.css`
